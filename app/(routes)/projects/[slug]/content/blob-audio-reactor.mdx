## Classes

I split the project into three classes. Each class has one clear job.

**AudioAnalyzer** handles all the sound, reading either a file or the microphone. Instead of an FFT it uses simple filters, because the blobs only need one smooth loudness value per band, updated every sample: a low-pass filter gives the bass, a high-pass filter the highs and both combined the mids. Three extra values compare two filters at slightly different cutoffs: how deep the sub-bass sits (40 Hz vs. 70 Hz), how bright the highs are (19 kHz vs. 11 kHz) and how hard a bass hit is.

<img src="/img/projects/blob-audio-reactor/analyzer-regler.webp" alt="Debug readout of the analysed audio values with hue slider, gradient slider and file / mic switch" className="doc-figure" />

**Blob** is one layer of the shape: 240 points around a centre, each shifted every frame by Perlin noise and scaled by the blob's loudness, which gives a soft, breathing outline instead of a plain circle. Four more effects apply only to specific blobs:

**Bass zigzag** (outermost blob): a fast, sharp sine wave in a narrow angle range, sized by sub-bass loudness and pointed by the sub-bass depth.

<img src="/img/projects/blob-audio-reactor/bass-zickzack.webp" alt="Bass zigzag on the outermost blob" className="doc-figure" />

**Bass shimmer** (outermost blob, opposite side): a soft, trembling wobble that only appears on hard, percussive hits.

<img src="/img/projects/blob-audio-reactor/bass-schimmer.webp" alt="Bass shimmer on hard bass hits" className="doc-figure" />

**Mid bubbles** (the two inner mid blobs): small circles that drift on their own noise and grow with the mids, capped so a bubble never reaches past the blob outside it.

<img src="/img/projects/blob-audio-reactor/mid-kreise.webp" alt="Mid bubbles on the inner mid blobs" className="doc-figure" />

**High shimmer** (innermost blob): a trembling wobble that moves up or down with the pitch of the highs.

<img src="/img/projects/blob-audio-reactor/high-schimmer.webp" alt="High shimmer on the innermost blob" className="doc-figure" />

Two more functions connect all eight layers: the wave pattern of each outer blob ripples inward, and a soft clamp pulls a point back if it would grow past the blob outside it.

**ofApp** connects everything: it creates the eight blobs, passes the analyzer values to the matching blob functions every frame and draws hand-built sliders and a file / mic switch without a UI library.

## Learning

Real-time audio is fragile: closing and reopening the microphone looked fine at first, but silently stopped sending data after a few tries, with no error message. Keeping the microphone stream open permanently fixed it. And a visually complex result benefits a lot from small, single-purpose classes and functions.

I used Claude as a tutor and debugging partner while I designed, wrote and tested the code myself.
